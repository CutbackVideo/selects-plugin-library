# Third-party components

This package contains source only. It does not include models, runtimes, generated footage, or installed dependencies.

- FFmpeg and FFprobe: https://ffmpeg.org/legal.html — used from the local Selects installation or the user's PATH. No binary is redistributed.
- Selects generated-media providers, including background-removal providers, are external services with their own terms and billing.
- React and Remotion APIs are provided by the Selects Panel and generated-media runtime.
- The optional local RVM route is documented separately in [rvm/THIRD_PARTY.md](rvm/THIRD_PARTY.md).
