# Third-party components

- React and Remotion are imported from the Selects host environment. This package does not redistribute those runtimes; the host's dependency versions and applicable terms govern their use.
- Times New Roman is requested by font-family name. Font files are not bundled. Verify their availability and appropriate licensing on each supported host platform.
- Users supply their own footage. No sample recordings, reference footage, or model weights are included.
- `place-count-theme.m4a`, the default music, was generated for Place Count with ElevenLabs Music v2.5 through the Selects generation service (prompt: an inspiring cinematic travel montage at 92 BPM, instrumental). ElevenLabs states Eleven Music output is cleared for commercial use, including video and social media; it must not be distributed as a standalone track on music streaming services. It was loudness-normalized to -16 LUFS and is otherwise unedited.
- Contact-image processing uses the host browser's media, canvas, and Web Crypto APIs and the Selects host FileSystem adapter.
