# Third-party components

- React and Remotion are imported from the Selects host environment. This package does not redistribute those runtimes; the host's dependency versions and applicable terms govern their use.
- Georgia and Arial are requested by font-family name. Font files are not bundled. Verify their availability and appropriate licensing on each supported host platform.
- Users supply their own footage and any music. No sample recordings, reference soundtrack, model weights, or other media are included.
- Contact-image processing uses the host browser's media, canvas, and Web Crypto APIs and the Selects host FileSystem adapter.
