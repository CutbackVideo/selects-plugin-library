# Third-party components

- React is imported from the Selects host environment. This package does not
  redistribute it; the host's dependency version and terms govern its use.
- `ffmpeg` is not bundled. When it is available, the panel runs it through the
  Selects shell to measure motion and build the candidate contact sheet.
- `assets/music.mp3` is an original track generated by Cutback with the
  ElevenLabs Music API under Cutback's paid plan. It contains no third-party
  recordings, samples or lyrics.
- Users supply their own footage. No sample footage, reference videos or model
  weights are included. The preview video shows AI-generated people.
