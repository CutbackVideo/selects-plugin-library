# Tang Poetry Explainer

Turn a link or text into a narrated historical collage film with ink-wash scenery, woodblock figures and editable titles.

1. Open a Project and choose **Tang Poetry Explainer** from Apps.
2. Paste a link or source text and set the target length.
3. Choose **Draft the script**, review it, then choose **Make the video**.
4. Open the saved Draft. Shots, narration, music, titles and captions remain separate clips. Historical figures are visibly illustrated reconstructions.
5. Use **Handoff → Export** for the final video.

Uses the signed-in user's Selects credits. Output is landscape 1920 × 1080 and follows the source language. Interrupted jobs can resume in their original Project.
