# Installation

## Requirements

- A compatible Selects development build on macOS.
- Panel support and generated-media authoring enabled.
- Host `FileSystem` and `SequenceRepository` adapters available.

Released-version and Windows/Linux compatibility are unverified.

## Install

Ask your Selects agent to install the **Timeline Shorts Builder** plugin from its Plugin Library folder link. The installer downloads only the files listed in `plugin.json`.

After installation:

1. Open a Selects project containing at least one editable Draft.
2. Open **Timeline Shorts Builder** from the Plugin list.
3. Choose a source Draft, set the layout ratio, and create a new Draft.

No external model, package manager, provider key, or manual runtime installation is required.
