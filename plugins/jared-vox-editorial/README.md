# Jared Vox Editorial

Turn a link or text into a narrated editorial film with archival paper, red marker accents and editable evidence cards.

1. Open a Project and choose **Jared Vox Editorial** from Apps.
2. Paste a link or source text and set the target length.
3. Choose **Draft the script**, review it, then choose **Make the video**.
4. Open the saved Draft. Shots, narration, music, titles and captions remain separate clips. Evidence cards are editable motion graphics.
5. Use **Handoff → Export** for the final video.

Uses the signed-in user's Selects credits. Output is landscape 1920 × 1080 and follows the source language. Interrupted jobs can resume in their original Project.

Review the generated Draft before export. Image checks can retry missing subjects or unwanted lettering, but extra props, count mismatches and small invented marks can remain. Titles, captions and evidence labels are editable overlays.
