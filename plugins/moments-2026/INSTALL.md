# Install 2026 Moments

Nothing to install beyond the standard layout:

- `panel.tsx` goes to `SELECTS_USER_PANELS_ROOT/moments-2026/panel.tsx`.
- `README.md`, `INSTALL.md` and `SKILL.md` go to `SELECTS_USER_SKILLS_ROOT/moments-2026/`.

## Requirements

- macOS or Windows with the Selects SDK. No Python, models or downloads.
- A project with at least one video of 9.6 seconds or longer for the intro, and
  other videos of at least 2.7 seconds. One long video can fill every slot.

## Check

Open **2026 Moments** with a project open. The 15 slots should fill
automatically; **Create Draft** saves a new Draft named `2026 Moments · <time>`
and opens it. The panel only creates new Drafts; it never changes existing
Drafts or source files.

## Uninstall

Delete the `moments-2026` folder from the panels root and from the skills root.
