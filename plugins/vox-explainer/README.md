# Vox Style Explainer

Give it a link or some text, and it makes a Vox-style explainer video from it.

## Use

1. Open a Project, then open **Vox Style Explainer** from Apps.
2. Paste a link, or choose **Text** and paste the text. Set the target length.
3. Press **Draft the script** and read the script.
4. Press **Make the video**. The video appears as an editable Draft in the Project.
5. Export it with **Handoff → Export**.
