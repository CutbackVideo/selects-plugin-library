# Short Form Safe Zones

Overlay platform safe-zone guides and composition grids on the main Draft
preview for TikTok, Reels, Shorts, Stories and LinkedIn, so on-screen text and
subjects stay clear of app buttons and captions before you export.

One toggle places the guides as a single clip on the top track of the open
Draft; turning it off removes that clip again. The guide clip is coloured
fuchsia and carries a "remove before export" label so it is never mistaken
for part of the final cut. The graphic reads the Draft's own size, so the
same clip works on both 9:16 and 16:9 Drafts.

## Controls

- **Show guides** — adds or removes the guide clip on the top track.
- **Platform** — TikTok, TikTok ad, Instagram Reels, Reels ad, Stories,
  YouTube Shorts, LinkedIn, or a Universal setting that combines the
  strictest margins across all of them.
- **Grid layers**, each independently toggleable:
  - Safe zones — the pink keep-clear margin and button-column step for the
    selected platform.
  - App UI mockup — a generic like/comment/share/caption mockup at that
    platform's real on-screen position (no real logos), so you can see what
    actually covers the frame.
  - Rule of thirds grid.
  - Centre lines.
  - Common crop guides.
  - Platform safe-area outline boxes.
- **Opacity** — 10–100%, so the guides can sit lightly over the footage.

## Info panel

Shows the exact keep-clear margins (top / bottom / left / right, in pixels
on the 1080 × 1920 reference frame) and button-column position for the
selected platform.

## Limitations

- Guide positions are measured from real app screenshots at one point in
  time; platform UIs change their layouts periodically.
- The guide clip must be removed from the top track before final export —
  it is a visual aid, not a burned-in safety mask.
