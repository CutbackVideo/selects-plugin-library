# Install Vlog Edit

This plugin is a Skill only. It contains no panel, no executable code, and no
dependencies.

1. Place this package in `vlog-edit` under `SELECTS_USER_SKILLS_ROOT`, so that
   `SKILL.md` sits at `SELECTS_USER_SKILLS_ROOT/vlog-edit/SKILL.md`.
2. Reload Selects. The skill is offered when you start a vlog or personal
   archive edit that mixes video with a large number of photos.

No external models, runtimes, credentials, or source-media files are included.
The procedure uses only the Selects editing SDK plus the bundled `ffmpeg` and
browser tooling already available to the agent.
