# Install

The Plugin Library places `panel.tsx` at `SELECTS_USER_PANELS_ROOT/medical-explainer/panel.tsx` and the Chosun Ilbo
logo used by the Chosun preset at `SELECTS_USER_SKILLS_ROOT/medical-explainer/assets/chosun-ilbo-logo.svg`. Nothing else
is downloaded or installed: the engine runs inside the panel. Working files are written beneath
`.selects/plugin-data/medical-explainer` in your home folder.

## Requirements

- macOS or Windows, with Selects 2.0.512 or later that offers media generation and plug-in storage to apps. If the app
  says "This Selects version cannot run this app" or asks you to update for plug-in storage, update Selects.
- Selects credits: images, video, voice and the optional music are generated by Selects and charged per generation.
- Nothing else to install: files go through Selects' own file access, and ffmpeg is the copy bundled with Selects.

## Check

Open a Project, open **Medical Explainer** from Apps and confirm the panel shows the Topic, Link and Text tabs, the
settings and template sections, and **Write the script**.
