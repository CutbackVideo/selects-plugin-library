# Install Ali Abdaal Style

Experimental: macOS arm64 and a compatible Selects development build.

1. Place this package in `ali-abdaal-style` under `SELECTS_USER_SKILLS_ROOT`.
2. Copy `panel.tsx` byte-for-byte to `SELECTS_USER_PANELS_ROOT/ali-abdaal-style/panel.tsx`.
3. Reload Selects, open a talking-head Draft, open the **Ali Abdaal Style** panel, and choose
   **Create Ali Abdaal Style draft**.

The panel reads Selects word timing when available. If the Draft has no transcript, the same
button starts source analysis and continues when analysis finishes. No external models, runtimes,
credentials, or source-media files are included.
