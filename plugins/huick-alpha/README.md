# Huick Alpha

Plan one short episode the way the team plans it in its Docs, then let Clipper
make the Draft with your template. The plan is the whole request: Clipper reads
the concept, cast, cutouts, materials and every scene's dialogue, screen
direction and article excerpt, picks the takes, cuts out the recordings and
places the graphics.

## Use

1. Import the Clipper template the episode uses (Clipper → Templates → Import,
   from a file or a share code). The panel starts with that template's Korean name
   (Huick Alpha · Common); change it if yours is named differently.
2. Put the raw recordings in one Draft and the photos, videos and sounds you
   found for the episode on disk. Open that Draft.
3. Open **Huick Alpha** from the Apps list and fill the plan:
   - **Concept and overall plan**: the episode title on the first line, then the
     concept, backgrounds, cutouts, and what every scene shares (logo, caption
     position, article cards). Describe sizes and positions as a person would:
     "right side, about two thirds of the screen height".
   - **Recordings**: turn on **Cut out** for each recording to cut out. Leave the
     request empty for green screen; write one line (for example "blue sky
     behind, use an AI mask") to let Clipper choose from it.
   - **Characters**: a name for each speaker, the recording that is them, and
     notes that apply to every scene they are in.
   - **Materials**: drop files one by one, or add every file in a folder.
   - **Scenes**: each scene's title, its lines exactly as spoken, the screen
     direction starting with the scene length and the beats in seconds, and any
     article excerpt with its source.
4. Press **Create in Clipper**. Clipper opens on the project and makes the
   Draft; follow it there. A run takes several minutes. If a recording marked
   for cutout still shows green screen, Clipper stops without saving a Draft.

The plan is saved per project in this panel, so it reopens where you left it.

## Notes

- One run makes one Draft from the open source Draft.
- Describe photos so similar ones can be told apart; file names are not needed.
- Graphics, captions, logo and sounds come from the template, not this panel.
