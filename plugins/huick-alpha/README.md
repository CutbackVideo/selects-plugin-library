# Huick Alpha

Plan one short episode the way the team plans it in its Docs, then let Clipper
make the Draft with your template. The plan is the whole request: Clipper reads
the concept, cast, cutouts, materials and every scene's dialogue, screen
direction and article excerpt, picks the takes, cuts out the recordings and
places the graphics.

## Use

1. Import the **&#xD719;&#xC54C;&#xD30C; · &#xACF5;&#xD1B5;** template in Clipper → Templates → Import,
   from a file or share code. Huick Alpha uses this template for every run.
   Click the template name next to **Template** to open its editor in supported
   Selects builds.
2. Open **Huick Alpha** in the project. Under **Files**, drop files or folders
   together, or choose files, folders, or existing project videos. All files
   appear in the same list as assets, and videos are available to characters.
   In **Remove background**, turn on the switch beside each video that needs it.
   Turning on a switch shows an optional note for that video. Describe the
   background so Clipper can choose how to remove it, or leave it empty for
   green screen.
3. Fill the plan:
   - **Concept and overall plan**: the episode title on the first line, then the
     concept, backgrounds, cutouts, and what every scene shares (logo, caption
     position, article cards). Describe sizes and positions as a person would:
     "right side, about two thirds of the screen height". Enter optional
     production credits in the field below the concept.
   - **Characters**: add a slot above the production plan. A numbered name is
     assigned automatically and can be edited on the card. Choose the
     character beside each line. The first character is assigned to unassigned
     lines. One character and one recording connect automatically when either
     one is added. The recording picker shows which footage has background
     removal enabled.
   - **Materials**: use **Reference asset** beside the scene's direction
     prompt to reference any added file.
   - **Scenes**: enter the title and lines as spoken. In the direction prompt,
     describe the scene length and when and how to use each asset. Add the article
     excerpt and source in the separate article field.
4. Press **Create Draft with Clipper** below the script. Huick Alpha prepares
   the videos linked to speaking characters, then Clipper opens on the project and makes the
   Draft; follow it there. A run takes several minutes. If a recording marked
   for cutout still shows green screen, Clipper stops without saving a Draft.

The plan is saved per project in this panel, so it reopens where you left it.

## Notes

- Huick Alpha makes a source Draft from the selected recordings and reuses it
  when the same recordings are submitted again.
- Describe photos so similar ones can be told apart; file names are not needed.
- Graphics, captions, logo and sounds come from the template, not this panel.
