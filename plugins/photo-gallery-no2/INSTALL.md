# Install Photo Gallery 21

Experimental Selects plugin for a 1080×1920, 60 fps, 3×7 gallery. It places the original JPG/PNG Image Resources directly as 21 independent Image clips; selected Video Resources stay video clips. Each tile has its own reveal time, crop focus, and grayscale-to-color effect. A black timeline gap supplies the 853-frame duration without importing a black MP4. Only a selected video shorter than the result is extended to a cached video that holds its final frame. No photo is transcoded and the complete gallery is never flattened.

Install `panel.tsx` in `SELECTS_USER_PANELS_ROOT/photo-gallery-no2/panel.tsx` and the other files listed in `plugin.json` in `SELECTS_USER_SKILLS_ROOT/photo-gallery-no2/`. The package requires Node.js, Python 3, and ffmpeg/ffprobe only for short-video extension and BPM analysis. It requires a 60 fps Project and public Selects SDK support for native `overlayResource(Image)`, Image dimensions in `project.sourceFiles()`, Video/Audio overlays, Effects, transforms, gap insertion, and Draft commit. The panel and chat use the same operation builder. Neither this package nor its tests change Selects client code.

Selects Staging 2.0.506 was tested with 21 real JPG Resources in a dedicated Project on September 29, 2026. The panel appeared, loaded the 21 photos, assigned them to all slots, and accepted manual BPM 113. Its create action stopped before saving because `project.sourceFiles()` exposed no Image dimensions. A direct, simulation-only SDK probe then confirmed `overlayResource(Image)` rejects the photo with `not a Video/Audio asset`; the Project still had zero saved Drafts. This native-photo version therefore cannot yet complete in Staging. See [STAGING_VALIDATION.md](STAGING_VALIDATION.md) for the exact test boundary. A separate Selects development worktree has the necessary Image-overlay API under development, but its live playback and export have not been validated for this plugin. The previous MP4-based alpha created and exported a reference-format Draft; that evidence does **not** establish this native-image version as complete. A gap-backed 853-frame Draft with one Video overlay was saved and exported successfully in isolated Selects 2.0.504, which only verifies removal of the black Main MP4. The live editor previously displayed black during overlay playback; this remains an acceptance failure until checked with native Images.

The current plugin creates new Drafts. Existing-Draft single-tile replacement is deliberately unavailable until the public Image replacement and semantic slot-binding APIs are integrated and proven to preserve other slots, manual effects, and crop. The 21 Image/Video clips themselves remain separate timeline objects. Do not claim the format is complete until the real panel and chat each create a Draft, a saved Draft is read back after restart, live editor playback works, native export matches `reference-oracle.json`, and supported media combinations pass.

For development, run `node --test builder.test.mjs format.test.mjs operation.test.mjs`, `python3 -m unittest hold_video_test.py tempo_test.py`, and `SELECTS_DEV_REPO=/path/to/selects node --test panel.behavior.test.mjs` from this folder. Set `PHOTO_GALLERY_REFERENCE` to a local copy of the source video for the optional reference-audio ambiguity test. Tests and reference media are not installed with the plugin.
