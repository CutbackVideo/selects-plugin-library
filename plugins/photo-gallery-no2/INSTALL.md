# Install Photo Grid Reveal

This experimental Selects plugin builds an editable 1080×1920, 60 fps, 3×7 gallery. Each original JPG/PNG stays an Image Resource on its own Video track. Video tiles remain Video Resources; only a selected video shorter than the output is extended to a separate cached MP4 that holds its last frame. The gallery is never flattened.

The reference's moving slots are 4, 6, 11, 17, 19, and 21. A matching motion pattern uses Videos in those slots and Images in the other 15. Other mixes are editable but do not reproduce that part of the reference format. If the Project has exactly 15 Images and 6 Videos, the panel can assign them to the observed slot types in one action.

Install `panel.tsx` at `SELECTS_USER_PANELS_ROOT/photo-gallery-no2/panel.tsx` and the files listed in `plugin.json` at `SELECTS_USER_SKILLS_ROOT/photo-gallery-no2/`. The generated panel is ready to install; contributors rebuild it from the repository template with `node build-panel.mjs`. Short-video extension runs inside the panel on Selects' bundled ffmpeg/ffprobe and writes its cached MP4s to `~/.selects/plugin-data/photo-gallery-no2/held-v2/` (no Python, the same on macOS and Windows). Optional BPM estimation runs `tempo.py` with a pinned CPython 3.11.13 that `runtime.sh` downloads on first use (through uv, checked by SHA-256) into `~/.selects/plugin-data/_runtime/`, shared with other plugins, and with the ffmpeg/ffprobe that ship with Selects. That first use needs an internet connection; a system `python3` is not used.

On Windows the panel builds the same Draft (photos, videos, short-video holding, the bundled music, manual BPM) through Selects' own file access and bundled ffmpeg, with no shell or Python. The BPM estimate is available on macOS for now: on Windows the panel keeps manual BPM and says so.

Music defaults to the bundled **Unexplored (long ver.) — TAD MILLER**, the selected 39.650–53.866667-second excerpt (14.216667 seconds). Create imports the asset once per Project and places it as an independent Audio clip. Choose another Project track or No music to override it. Manual BPM defaults to 113 to preserve the reference timings; it is a timing control, not a measured BPM of this music. Disable manual BPM to estimate a selected track. Longer results need a longer track; the excerpt is never looped or padded. Keep the attribution, source, license link, and change notice from [THIRD_PARTY.md](THIRD_PARTY.md) when sharing music or finished videos. The panel displays this credit and the MP3 includes it in metadata.

The public Selects SDK currently rejects `overlayResource(Image)` and omits Image dimensions from its source-file inventory. The panel uses the app-owned `TimelineMutation` service through its documented panel `window.parent.__DI__` access to place original Images; it checks the open Project, exact media paths, dimensions, and Draft ownership before editing. It uses the public SDK for Video and Audio overlays, effects, transforms, persistence, and readback. This panel host route is provisional and must be retested after a Selects update. No Selects client source is changed.

The Selects chat skill and panel share the planner, preflight, styling, and verification operation. Image placement itself requires the panel host and is not exposed to `run_script`. A chat agent with app-control tools can operate the same panel on the user's behalf; the skill directs it to use that route instead of asking the user to repeat clear choices or click the button. A live No.2 chat request has created and structurally verified a 15-Image/six-AI-Video Draft through the installed panel. Playback remains a separate acceptance gate; see [VALIDATION.md](VALIDATION.md). Without app control, chat must identify the concrete remaining panel action. Chat can also inspect inputs and, only when a new Draft already uses 60 fps, create an all-Video gallery through the public operation. Do not generalize this creation run into universal chat/panel parity or end-to-end one-shot reliability.

The panel currently creates a new Draft and offers individual clip editing in the Selects timeline. Automated replacement of one tile in an existing Draft is not yet supported. Never rebuild a Draft without explicit instruction or claim unrelated manual edits are preserved by a replacement operation.

Run `SELECTS_DEV_REPO=/path/to/selects node --test *.test.mjs` and `python3 -m unittest tempo_test.py` from this folder. See [VALIDATION.md](VALIDATION.md) for live results and outstanding cases.
