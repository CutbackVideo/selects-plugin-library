# Install Photo Gallery 21

Experimental Selects plugin. It converts each selected Project photo into a separate silent 60 fps Video Resource and places 21 independent clips over one full-length black Main video in a new 1080×1920 Draft. Short videos are extended by holding their last frame; videos already long enough remain untouched. Conversion caches are durable under `~/.selects/plugin-data/photo-gallery-no2/`; keep those files available to the Project. The full gallery is never flattened into one video.

Install `panel.tsx` in `SELECTS_USER_PANELS_ROOT/photo-gallery-no2/panel.tsx` and all other files listed in `plugin.json` in `SELECTS_USER_SKILLS_ROOT/photo-gallery-no2/`. The package requires Node.js, Python 3, ffmpeg/ffprobe available to Selects `runShell`, and a Selects build with public Project media import, Draft Video Resource overlays, effects, transforms, and commit APIs. Current packaged Selects shell code provides bundled ffmpeg/ffprobe as a fallback when they are absent from the login-shell PATH. The plugin does not modify Selects client code or automatically install dependencies. A 60 fps Project is required; the SDK has no public Project frame-rate setter. Released-build compatibility remains unverified. The isolated development build passed frame capture and native MP4 export; its editor preview is blank in this environment.

The public SDK cannot yet guarantee plugin-driven single-tile replacement that preserves manual edits. That action stops without a Draft commit. The 21 created Video clips remain individually editable through Selects' normal timeline UI. Do not advertise this alpha as a complete reference-format reproduction until editor playback and all supported input combinations pass comparison with the oracle. The Main video establishes the editor's 14-second duration, but the isolated app's playhead has not advanced during playback testing.

For development, run `node --test builder.test.mjs format.test.mjs operation.test.mjs`, `python3 -m unittest black_base_test.py still_video_test.py hold_video_test.py tempo_test.py`, and `SELECTS_DEV_REPO=/path/to/selects node --test panel.behavior.test.mjs` from this folder. Set `PHOTO_GALLERY_REFERENCE` to a local copy of the source video to run the reference audio ambiguity test. Tests and reference media are not installed with the plugin.
