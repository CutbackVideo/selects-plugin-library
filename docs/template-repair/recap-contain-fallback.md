# Recap: source-preserving framing for unfit or undetected face observations

The production preparation now selects native full-source fit only for valid `no-faces` or `cannot-fit` observations. It preserves those diagnostic statuses rather than reporting a successful face detection. Existing manual cover focus wins. Successful feasible face focus, unsupported/failed/incomplete analysis, source selection and all timing/music/title authoring retain their previous policies.

`containBySlot` records frame-independent uniform geometry separately from sampled face positions. Both the intro and batched clips receive it. If the actual Project frame grid differs from the one used to observe source windows, automatic face positions are still discarded, while source-preserving fit and manual geometry remain valid. Every selected transform still requires the existing persistent resource/path binding and byte fingerprint guards before authoring.

The 1920×1080 example fits into1080×607.5 within a1080×1920 output, leaving656.25 pixels above and below. The alternative therefore reduces source size and adds margins. It cannot recover outside-source pixels or guarantee preservation of a person the detector missed while detecting somebody else; a `cannot-fit` union can also be a single moving face across samples.

`tests/recap_contain_fallback.test.mjs` executes the entire production panel through real beat planning, preparation, serialized intro/batches/song/title scripts and commits, with public SDK/IO boundaries simulated. It covers no-faces/cannot-fit, different actual fps, same resource with distinct manual/automatic slots, valid observation versus unsupported/error/unobserved states, scope disposal, source bytes/alias changes, unchanged source windows/music/title, and structural TypeScript compilation of the actual emitted scripts. A separate contract test requires genuine public SDK declarations when available and reports an explicit skip when they are absent; structural compilation alone is not SDK compatibility proof. An explicitly configured but invalid declaration path fails. The previous manual-source regressions use an extracted whole-module fixture without changing their assertions or production boundaries.
