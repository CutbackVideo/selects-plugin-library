# Selects Plugin Library

Plugins for editable Selects Drafts. Download individual plugins without a GitHub account.

| Plugin | Status | Download |
| --- | --- | --- |
| [Portrait Stage](plugins/portrait-stage/SKILL.md) | Experimental | [Release](https://github.com/CutbackVideo/selects-plugin-library/releases/tag/portrait-stage/v0.1.0-alpha.2) |

Download the named plugin ZIP, then ask your Selects agent to follow its `INSTALL.md`. Models and runtimes are installed separately. Export finished videos through **Handoff → Export**.

Each plugin has its own version and ZIP. You do not need to download the entire library.

For maintainers: [Publishing](PUBLISHING.md).
